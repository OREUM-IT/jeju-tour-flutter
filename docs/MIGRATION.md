## 서버 계약

기본 응답은 `{ "success": true, "data": ... }`이며, 실패는 `success: false`, `message`, 선택적인 검증 상세 `data`입니다. HTTP 실패·응답 형식 오류·연결 오류·시간 초과를 사용자에게 표시합니다. 기상/관광 자료를 가짜 값으로 대체하지 않습니다.

주요 경로:

- GET `/meta`, `/course/places`, `/weather`
- POST `/plan` — 조건으로 일정 생성. `/products` 저장을 호출하지 않음
- GET `/route/presets`, `/route/presets/:id`
- POST `/route/plan`, `/route/analyze`
- GET `/challenge/meta`, `/challenge/sessions`, `/challenge/hall`
- POST `/challenge/start`, `/challenge/sessions/:id/finish`, `/challenge/sessions/:id/weather`
- GET `/kma/status`, `/kma/now?lat=...&lon=...`, `/kma/aws`, `/kma/warnings`

사진은 원본 EXIF를 읽고 방향을 적용한 뒤 긴 변 1,200px 이하 JPEG로 압축합니다. EXIF에 촬영 시각이나 GPS가 없으면 새로 만들지 않습니다. 서버 인증에 사용하는 GPS는 기기에서 측정한 좌표이며 2분이 지난 값은 재측정을 요구합니다. 인증 승인 결과를 클라이언트에서 생성하지 않습니다.

## 이후 원본 소스 확보 시 대조할 항목

원본 서버 엔진, 사용자별 인증·권한·영구 저장, 코스 최적화·교통 시간표, 단독 인증·관리자 흐름, 다국어·GPX 가져오기와 데이터 이전. 이 저장소는 해당 부분이 완전히 변환됐다고 가정하지 않습니다.

## 검증 경계

정적 분석·자동 테스트·웹 빌드와 공개 조회 API를 검증합니다. 실제 위치·사진의 인증 제출은 운영 기록을 생성하므로 자동 검증에서 수행하지 않습니다. Android/iOS 플랫폼 파일은 포함하지만 앱스토어 서명·배포, 기기별 위치/카메라 권한과 백그라운드 복원, 영구 서버 저장은 이 작업의 웹 검증으로 보장되지 않습니다.
