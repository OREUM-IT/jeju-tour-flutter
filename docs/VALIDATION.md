2026-11-16 · Windows · Flutter 3.47.6 / Dart 3.13.5

- `flutter analyze`: 문제 없음.
- `flutter test`: 14개 통과. 한글 API 입출력·오류·시간 초과, 일정 생성 조건, 좌표 검증, 코스 순서·영업시간·날짜 경계, 저장·삭제·복구, 잘못된 저장 JSON, 사진 처리·EXIF 미조작, 폭 360/1280의 기본 화면·이용안내를 확인했습니다.
- `flutter build web --release --no-web-resources-cdn --no-wasm-dry-run`: JavaScript 기반 웹 릴리스 빌드 성공. WASM 빌드를 검증한 것은 아닙니다.
- 공개 서비스 API: 메타데이터, 장소 목록, 일정 생성, 기상청 실황·AWS·특보, 예보, 경로 프리셋·분석 응답 확인. 인증·저장·삭제 등 운영 기록을 변경하는 요청은 실행하지 않았습니다.
- 브라우저: 로컬 미리보기 서버는 시작됐으나 이 환경의 `127.0.0.1:8080` 연결이 시간 초과되었습니다. 실제 브라우저에서 지도·메뉴·네트워크를 포함한 종합 동작 검증은 **미완료**입니다.
- Android/iOS: 플랫폼 프로젝트와 권한 설정 포함. APK/IPA 빌드·서명·기기 테스트는 수행하지 않았습니다.

웹 빌드 ZIP은 정적 파일입니다. 기존 API와 함께 실행하려면 소스 ZIP을 풀고 `build/web`에 웹 빌드 내용을 넣은 뒤 `python scripts/preview.py`를 실행하거나, `vercel.json`의 프록시 설정으로 배포합니다. ZIP 안의 `index.html`을 파일 탐색기에서 직접 여는 방식은 지원하지 않습니다.
